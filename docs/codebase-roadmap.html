1. Current Codebase Architecture Overview

High-integrity stack strictly enforcing type safety, memory bounds, and macOS menu-bar ergonomics.

Main Process & Windows
Electron 41

Runs silently in menu-bar mode (app.dock.hide()). Coordinates floating windows, native bridge, and background health.

  • Single-Instance Lock: Atomic marker signal resurfaces Settings without duplicate process.
  • Panel Throttling Disabled: backgroundThrottling: false keeps idle panels hot.
  • Wake Resilience: PowerMonitor reasserts status item and syncs state on macOS wake.
  • State Persistence: Atomic temp-rename JSON storage in Application Support.
Renderer & Design System
React 19

Pure Vanilla CSS (no Tailwind) with custom tokens for macOS Tahoe / Sequoia vibrancy and fluid micro-animations.

  • ShelfView: Spring-physics drag dropzone with item badges, color themes, and quick actions.
  • QuickPastePalette: Spotlight-style search for clipboard history with plain-text paste.
  • NotchDropoutView: Dynamic island drop detection near MacBook camera cutout.
  • PreferencesView: Multi-tab settings with live OS login-item status reflection.
Native Swift & Convex Sync
Swift + Cloud

Low-overhead native Swift subprocess paired with optional cloud sync and subscription billing.

  • DropShelfNativeAgent: CoreGraphics event tap for shake gestures and bookmark security.
  • Per-Item Lexorank: Fractional indexing on shelfItems prevents conflict storms.
  • Storage Pipeline: Bounded 1.5GB/hr image asset upload rate with automatic cleanup crons.
  • Billing Integration: Webhook deduplication for Lemon Squeezy Pro entitlements.
